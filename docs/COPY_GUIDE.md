# 한국어 문구 가이드

화면과 알림에 쓰는 문구의 기준입니다. 근거는 [계획서 2.1 표현 원칙](IMPLEMENTATION_PLAN.md)입니다.

이 서비스는 **움직임 신호를 알려 주는 도구**입니다. 낙상이나 배회를 예방하거나 확실히 감지하지 않고, 신호 하나로 진단·사고 판정을 하지 않습니다.

## 쓰지 않는 표현

`packages/shared/src/copy.ts`의 `FORBIDDEN_PHRASES`가 기준이며, 아래 문구를 포함하면 테스트가 실패합니다.

`낙상` · `배회` · `이탈` · `안전합니다` · `이상 없음` · `예방` · `사고` · `진단` · `확실`

| 쓰지 않는 표현                | 쓰는 표현                                                                 |
| ----------------------------- | ------------------------------------------------------------------------- |
| 낙상이 발생했습니다           | 침대 주변에서 움직임이 감지되었습니다.                                    |
| 배회 중입니다                 | 짧은 시간 안에 여러 구역에서 움직임이 감지되었습니다.                    |
| 침대에서 이탈했습니다         | 침대 주변 센서에서 움직임 신호가 있었습니다.                              |
| 안전합니다 / 이상 없음        | 새로운 알림이 없습니다.                                                   |
| 사고를 예방합니다             | 보호자가 확인하는 데 도움을 줍니다.                                       |

## 상태를 말하는 방법

- **"정상"이라고 하지 않는다.** 센서가 연결되어 있고 열린 알림이 없을 때만 "모니터링 중 — 새로운 알림이 없습니다"라고 쓴다.
- **센서가 없거나, 끊겼거나, 첫 신호를 기다리거나, 배터리가 부족하거나, 알림 전달에 실패했으면** "모니터링 불완전"과 이유를 함께 보여 준다. 열린 알림이 있어도 이유는 같이 표시한다.
- **확인하지 못했으면** "상태 확인 불가"라고 쓴다. 이전에 받은 내용은 "마지막으로 확인한 상태"로만 덧붙인다.
- "서버 연결됨"은 서버가 응답한다는 뜻이다. 어르신의 상태를 말하는 표현으로 쓰지 않는다.

| 상태                 | 화면 문구        | 아이콘          |
| -------------------- | ---------------- | --------------- |
| 모니터링 중          | 모니터링 중      | `CircleCheck`   |
| 주의                 | 확인 필요        | `TriangleAlert` |
| 긴급                 | 즉시 확인 권장   | `BellRing`      |
| 센서·전달 문제       | 모니터링 불완전  | `WifiOff`       |
| 확인하지 못함        | 상태 확인 불가   | `CircleHelp`    |

상태는 **색 + 아이콘 + 글자** 세 가지로 전달합니다. 색만으로 구분하지 않습니다.

## 실제·가짜·미연동을 구분한다

| 표시                | 뜻                                                    |
| ------------------- | ----------------------------------------------------- |
| 실제 연동           | 실제 서비스와 연결되어 있음                           |
| 가짜 응답(테스트용) | 실제 전송 없이 가짜 응답으로 동작함                   |
| 연동되지 않음       | 설정되지 않음. 보낸 척하지 않는다                     |
| 시뮬레이션          | 시뮬레이터가 만든 데이터. 실제 센서 데이터와 구분한다 |
| 샘플 데이터         | 개발 중 Mock으로 채운 화면. 실제 데이터가 아니다      |

## 문장 쓰는 법

- 존댓말(`~습니다`)을 쓰고, 한 문장에 한 가지만 말한다.
- 오류는 **무슨 일이 일어났는지**와 **다음에 할 일**을 쓴다. ("서버에 연결할 수 없습니다. 서버가 켜져 있는지 확인해 주세요.")
- 보호자를 겁주거나 안심시키는 표현을 쓰지 않는다. 사실(감지된 움직임, 끊긴 센서 수)을 말하고 확인을 권한다.
- 돌봄 대상은 별칭(예: "어르신")으로만 부른다.

## 문구가 있는 곳

| 곳                                       | 내용                                              |
| ---------------------------------------- | ------------------------------------------------- |
| `packages/shared/src/copy.ts`            | 알림 제목·본문 (서버가 만들고 화면이 그대로 보여 줌) |
| `packages/shared/src/domain.ts`          | 구역·민감도·센서 상태 이름                        |
| `packages/shared/src/integrations.ts`    | 알림 채널·연동 방식 이름                          |
| `apps/web/src/lib/labels.ts`             | 알림 수준·배터리·출처·샘플 표시                   |
| `apps/web/src/features/dashboard/`       | 대시보드 상태 문장(`deriveOverallStatus.ts`)      |

새 문구를 추가하면 `copy.test.ts`(shared)나 `labels.test.ts`(web)에 함께 검사하도록 넣습니다.
