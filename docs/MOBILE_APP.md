# 노크 앱 (iOS · Android, React Native)

보호자가 휴대폰으로 노크 알림을 받는 앱입니다. `mobile/` 폴더의 **Expo(SDK 58) + React Native 0.88** 프로젝트이며, 한 코드로 iOS·Android 를 모두 만듭니다. 화면 디자인은 Claude Design 캔버스 "노크 앱·웹 디자인"의 앱 화면 5장을 따릅니다.

> 앱은 웹과 같은 서버(`apps/server`)에 붙습니다. 서버의 기능·규칙은 그대로이고, 앱은 **알림을 받고 확인하는 보호자용 화면**입니다. 센서 등록·감지 설정·시뮬레이터 같은 관리 기능은 웹에서 합니다.

## 화면

| 화면 | 하는 일 |
|---|---|
| 로그인 | 서버 주소·이메일·비밀번호. 시뮬레이터 기본 주소는 iOS `http://localhost:4000`, Android 에뮬레이터 `http://10.0.2.2:4000` |
| 지금 상태 | 큰 상태 카드(즉시 확인 권장 / 확인 필요 / 모니터링 불완전 / 센서 없음 / 상태 확인 불가 / 모니터링 중), 실시간 연결·시뮬레이션 여부, 구역별 센서(연결·배터리·마지막 신호). 아래로 당기면 새로 읽음 |
| 알림 | 전체 / 진행 중, 심각도·처리 상태·읽음 표시, 시뮬레이션 표시. 탭 배지에 읽지 않은 수 |
| 알림 상세 | 문구, 근거 신호, **알림과 함께 온 영상 재생**(시연용 웹캠), "확인했습니다"·"알림 종료". 열면 읽음 처리 |
| 설정 | 알림 소리·진동, 긴급 알림만 받기, 휴대폰 알림 권한, 테스트 알림, 서버 연결 상태, 로그아웃 |

## 알림을 받는 방식 (정직하게)

- 앱이 **실행 중일 때**(앞에 있거나 잠시 뒤로 간 동안) 서버와 실시간 연결(Socket.IO)을 유지하고, 서버가 보내는 `alert.notify` 를 받으면 **휴대폰 알림(배너·소리·진동)** 을 띄웁니다. 알림을 누르면 그 알림 상세로 갑니다.
- **앱을 완전히 닫았거나, 휴대폰이 앱을 오래 멈춰 두면 알림이 오지 않을 수 있습니다.** 그때 알림을 받으려면 원격 푸시(APNs·FCM, 예: Expo 푸시)가 필요한데, 이것은 Apple 개발자 계정·Firebase 프로젝트가 있어야 해서 **이번에 구현하지 않았습니다.** 앱 설정 화면과 첫 화면에 이 한계를 적어 두었습니다.
- 앱이 다시 앞으로 오거나 실시간 연결이 다시 이어지면, 놓친 알림을 서버 API 로 다시 읽어 맞춥니다.

## 서버 쪽 변경

- `POST /api/auth/mobile/login` — 앱용 로그인. 쿠키 대신 **세션 토큰을 본문으로** 돌려줍니다(`token`, `expiresAt`, 보호자·가구). 비밀번호 확인·시도 제한(15분 5회)은 웹 로그인과 같습니다. `Cache-Control: no-store`.
- 사용자용 API 는 쿠키 외에 `Authorization: Bearer <세션 토큰>` 도 받습니다(`readSessionToken`). Bearer 는 브라우저가 자동으로 붙이지 않으므로 CSRF 대상이 아닙니다. 로그아웃도 Bearer 로 하면 그 세션을 끊습니다.
- 실시간 연결은 쿠키가 없으면 `auth.token` 으로 인증합니다. 다른 가구의 실시간 이벤트는 받지 않습니다.
- 영상 재생도 같은 토큰을 헤더로 보냅니다(`expo-video` 의 `headers`).
- 시험: `apps/server/src/modules/auth/mobile-auth.routes.test.ts` (8개: 토큰 로그인·쿠키 없음, 토큰으로 내 데이터만, 쿠키·Origin 없는 요청의 확인 처리, 잘못된 토큰 401, 로그아웃 후 401, 시도 제한, 실시간 연결 인증·가구 분리, 실시간 연결 거부)

## 보안·개인정보

- 세션 토큰은 기기의 **보안 저장소**(`expo-secure-store`: iOS 키체인, Android Keystore)에만 둡니다. 화면이나 로그에 쓰지 않습니다.
- 만료(14일)되었거나 서버가 401 을 주면 로그아웃 상태로 돌아갑니다.
- **개발용 설정:** 집 안의 개발 서버(`http://`)에 붙도록 iOS 는 `NSAllowsArbitraryLoads`, Android 는 `usesCleartextTraffic` 를 켰습니다(`mobile/app.json`). **실제로 배포하려면 서버를 https 로 두고 이 두 설정을 끄세요.**

## 실행

```bash
# 1) 서버 (저장소 루트에서)
npm run dev

# 2) iOS 시뮬레이터 (mobile/ 에서, Xcode·CocoaPods 필요)
cd mobile && npx expo run:ios

# 3) Android 에뮬레이터 (Android SDK·JDK 17 필요)
cd mobile && npx expo run:android
```

- 실제 휴대폰에서 쓰려면 서버를 같은 네트워크에서 접속할 수 있게 열고(`SERVER_HOST=0.0.0.0`), 로그인 화면의 서버 주소에 Mac 의 IP(예: `http://192.168.0.12:4000`)를 넣습니다.
- `ios/`·`android/` 폴더는 `expo prebuild` 가 만드는 생성물입니다. 직접 고치지 말고 `app.json` 을 고칩니다.
